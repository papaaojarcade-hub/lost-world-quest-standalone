# The Lost World VR - Quest Stand Alone, version 1

First release of the standalone Quest build of The Lost World, a fork of [headsplosion's original PC VR project](https://github.com/headsplosion/lost-world-supermodel-pcvr) - thank you to its creator.

**Included:** runs entirely on Quest 2 / Pro / 3 / 3S; two-player over Wi-Fi or the internet (room codes, public game list, UPnP), voice chat, partner aim ring; CHEATS tab (stage select, infinite health, endless ammo, free play, credits; host-only in two-player); tuned VR preset; own icon and app id `com.papas.lostworldstandalone`.

**Install:** download `LostWorldVR-quest.apk` below, install it with Meta Quest Developer Hub, SideQuest or `adb install -r`, start it once, then copy your own `lostwsga.zip` to `Android/data/com.papas.lostworldstandalone/files/ROMs/` and start it again. Full steps and controls are in the README.

No game files are included. This is a new app id: if you used an earlier test build, copy your ROM and saves over.
